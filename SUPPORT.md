# Getting help

| You want to… | Go here |
|---|---|
| Report a bug in NXCodes | [nxcodes-feedback → New issue](https://github.com/One-Mans-Junk/nxcodes-feedback/issues/new/choose) |
| Ask how to do something | [Discussions](https://github.com/One-Mans-Junk/nxcodes-feedback/discussions) |
| Read the documentation | [nxcodes-docs](https://github.com/One-Mans-Junk/nxcodes-docs) |
| Report a security problem | [Private vulnerability report](https://github.com/One-Mans-Junk/nxcodes-feedback/security/advisories/new) |
| Hear when NXCodes launches | [nxcodes.com](https://nxcodes.com) — join the waitlist |
| See the other games | [onemansjunk.games](https://onemansjunk.games) |

NXCodes is in development and not yet for sale, so there's no paid support yet. Licensed owners will get priority support after launch.
