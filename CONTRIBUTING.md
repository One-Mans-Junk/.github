# Contributing

Thanks for wanting to help. Most One Man's Junk code — including the NXCodes engine — is proprietary and lives in private repositories, so the best ways to contribute are:

- **Report a bug** or **request a feature** for NXCodes in [nxcodes-feedback](https://github.com/One-Mans-Junk/nxcodes-feedback/issues/new/choose). The forms ask for what we need — please fill them in.
- **Ask for an addon hook** if you're building an NXCodes addon and the engine doesn't give you what you need (there's a form for that too).
- **Fix the docs.** [nxcodes-docs](https://github.com/One-Mans-Junk/nxcodes-docs) is public; pull requests with corrections are welcome.
- **Ask questions and show off** what you've built in [Discussions](https://github.com/One-Mans-Junk/nxcodes-feedback/discussions).

## Before you open an issue

- Search first — someone may have reported it already.
- One problem per issue.
- Include your NXCodes version, PHP version, and hosting type for bugs.
- **Security problems are never public issues.** See [SECURITY.md](SECURITY.md).

## Pull requests to public repositories

Keep them small and focused, explain what and why, and use American English in any user-facing text. By submitting a pull request you agree it can be used in One Man's Junk projects under that repository's license.
