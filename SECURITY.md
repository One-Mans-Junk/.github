# Security Policy

Please **do not** report security problems in public issues, discussions, or pull requests.

Report them privately: <https://github.com/One-Mans-Junk/nxcodes-feedback/security/advisories/new>

Tell us which project and version is affected, what an attacker could do, and how to reproduce it. We'll acknowledge the report, work on a fix, and credit you when it ships if you'd like.
